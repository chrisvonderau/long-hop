# Long Hop: Red Centre Run

A cartoon outback lane-crossing adventure. Play Mara, a red kangaroo, hopping and leaping across highways, rivers, gorges and billabongs. Scores are in Australian dollars, and there are four bonus rounds, three difficulties, unlockables, and a well-hidden cold secret.

Play in the browser: open `index.html`, or use the GitHub Pages link for this repository. It is one offline file, with no account and no network.

Controls (Xbox controller, keyboard, and touch) are in `CONTROLLER.txt`. Test results are in `TEST_REPORT.md`.
